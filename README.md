# Malmin Korupaja · Volcano-kokeilu

Puhelin-ensin -sovellus, jolla [Volcano-sormuksen](https://www.korupaja.fi/volcano.html) voi kokeilla omassa kädessä kameran kautta reaaliajassa.

## Käynnistys

```bash
npm install
npm run dev
```

- Tietokone: https://localhost:5173/
- Puhelin samassa Wi-Fi-verkossa: käytä terminaalissa näkyvää Network-osoitetta (HTTPS). Hyväksy selaimen varmennevaroitus, jotta kamera toimii.

Avaa kamera, näytä käsi, valitse sormus ja ota kuva tai video. Työpöydällä voi kokeilla myös esimerkkikädellä.
